## 永遠的第一步，思考這個產品的全貌

要寫出一個管理後台，可以管理職缺，有基本的 CRUD。還要實作簡單的前台讓大家看到有哪些職缺。

得到這個需求之後，第一步，必須要有大致上的輪廓。通常都是 PM 會處理好。

通常會使用 user story 使用者故事來描述所需要作到的事情以及功能。

1. 身為一個使用者，我可以看到職缺
2. 身為一個使用者，我可以看到薪水範圍
3. …

一個重點是，必須要有：管理後台以及前台

-

前台，可能需要一個 list，展現出所有職缺的頁面，順便取名頁面的檔名。

```
index.php // 展現所有職缺
**
***
*
****
```

我們可能會需要一個功能，就是查看單一職缺的詳細訊息。所以要有一個頁面來呈現，那可能需要檔案，後面接那個職缺的 ID。（題目沒要求，但還是可以實作）

```
job.php?id=1
```

-

管理後台：

admin.php 顯示所有職缺

add.php 新增職缺

update.php 更改職缺

刪除職缺，因為比較簡單，也許可以直接做在 admin.php 上面，只要有個叉叉，按下去就可以刪除。

在第一階段，就必須要想出來，可能會有哪些頁面，這些頁面需要做些什麼事情。像是新增職缺的部份，可能只是一個可以放入資料的頁面，而實際送上伺服器，可能又需要另外一個 php 來處理，協助真的把資料上傳，handle_add.php 這其實只是一個功能性的 php 也許根本沒有頁面。這就只是協助真的上傳資料，上傳之後會在返回顯示所有職缺的頁面。

然後產品也不可能一開始就全部定調完成。所以有可能隨著實作的部份，就發現需要新增頁面，那就留待碰到的時候再來思考了。

總而言之，前台需要：

index.php 展現所有職缺

job.php?id=1 展現單個職缺

管理後台：

admin.php 顯示所有職缺

handle_add.php 下 SQL 指令新增職缺，不需要畫面

update.php 更改職缺

這部份就只是思考一下，大概有整畫面，可能的話，可以以之前看過得東西為藍圖。

## 撈取資料庫資料

打開 index.php 然後在第一行新增 php 語法。然後引入資料庫資料。

接著在需要變動資料的部份新增 php 標籤。一樣要先新增 $sql 去接收選資料指令。

```
$sql = "SELECT * FROM jobs ORDER BY created_at DESC";
```

然後把上傳資料的指令賦給 $result ，這樣之後才可以呼叫

```
$result = $conn->query($sql);
```

接著就可以利用 $result 的屬性去撈資料。透過 num_rows 來得知總共有幾筆資料，如果大於 0 筆（也就是有 1 筆以上），就透過 fetch_assoc() 來取得資料。

> fetch_assoc() 的作用是可以拿到一筆資料，而當拿不到資料之後，就會回傳 false

```
if ($result->num_rows>0) { // num_rows 會告訴有幾筆資料。
 $result->fetch_assoc();
}
```

為了要可以取得所有資料，就可以利用 while 迴圈包起來。

```
if ($result->num_rows>0) { // num_rows 會告訴有幾筆資料。
 while($result->fetch_assoc()) {

 }
}
```

當有資料的時候，就是 true，就會執行 while 迴圈裡面的資料，而當回傳是 false 沒有資料之後，就會跳出 while 迴圈。

while 迴圈裡面就可以放需要顯示的資料。裡面有兩種寫法。一個是使用 echo，直接印出需要的標籤跟資料。另外一種是使用中斷 php 放一些 html 標籤，然後在用 php 去執行。第二種會長得像下面那樣：

```
if ($result->num_rows>0) { // num_rows 會告訴有幾筆資料。
 while($result->fetch_assoc()) {
  ?>
    <div> hello world </div> // 可以寫 html
  <?php // 繼續 php 的部份。
 }
}
```

這邊先使用 echo 的方式。利用 echo 的方式還有一點要小心，因為在寫標籤的時候，class name 必須要用引號包住，所以這時候 echo 包住的部份就要改用另外一種引號， class name 才可以可以保持原來的，否則字串的判斷就會失準。在這邊測試之後發現，只需要引號不同就可以正常顯示。

```
if ($result->num_rows>0) { // num_rows 會告訴有幾筆資料。
 while($row = $result->fetch_assoc()) {
  echo $row['title'];
  echo '<div class="job">';
  echo   '<h2 class="job__title">' . $row['title'] . '</h2>';
  echo   '<p class="job__desc">' . $row['description'] . '</p>';
  echo   '<p class="job__salary">薪水範圍' . $row['salary'] . '</p>';
  echo   '<a class="job__link" href="' . $row['link'] .
   '">更多資訊</a>';
  echo "</div>";
 }
}
```

利用這段就可以正確呈現網頁。

## 實作編輯與刪除功能

在刪除功能這邊當我們點下去之後，是使用 get 的形式傳上去的。什麼是 get 的形式呢？ 就是 /admin.php?key=value&a=b，所以就可以新增一個 delete.php 來寫入 php 的程式碼。

發現按下去之後會印出相對應的 id，所以是 ok 的。剩下來要做的就是把 id 的資料刪掉而已。

```
  require_once('./conn.php');
```

[PHP strtotime() 函数](http://www.w3school.com.cn/php/func_date_strtotime.asp)

所以就判斷一下，讓截止日期大於等於現在時間的資料印出即可。也就是說只讓截止日期還沒到的印出資料就好。這樣前台的部份就完成了。

```
if ($result->num_rows>0) { // num_rows 會告訴有幾筆資料。
 while($row = $result->fetch_assoc()) {
  // 判斷寫這邊。
  $due_date = $row['due_date'];
  $datetime = date ("Y-m-d" , mktime(date('H')+8, date('i'), date('s'), date('m'), date('d'), date('Y')));
  if (strtotime($due_date) >= strtotime($datetime)) {
   echo '<div class="job">';

    '">更多資訊</a>';
   echo "</div>";
  }
 }
}
```

## 魔王練習：開放會員註冊並且管理職缺

因為管理的頁面通常是只有管理者知道位置。而這邊就是要讓人有管理權限。要在 index.php 上面新增一個頁面可以註冊或登入。然後就可以進入後台，然後只能夠新增、編輯、刪除自己的職缺，每個人有不同的管理後台。當然自己有一個 super admin，可以一次管理所有人的職缺。這就牽扯到權限上的設置。所以是很有難度的。可以從讓人獨立帳號可以新增職缺開始試試看。
