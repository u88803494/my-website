## 前置作業：

1. 先開設好 GitHub page 的功能，理當設置好之後，帳號裡面會有一個叫做 [你的帳號].github.io 的 repository。
2. 在 GitHub，新增一個 repository，這邊的命名，會影響到 github.io 的子資料夾名稱。例如設置一個 repository 叫做 littlewang，當佈署好之後資料就會放在 [你的帳號].github.io/littlewang 裡面。  
   記得不要勾選 Initialize this repository with a README
3. 複製的指令 `git remote add ...`
4. 開 command line 切到想要佈署的 react app 資料夾
5. 使用 `git remote add ...` 把資料夾跟 GitHub repository 串在一起
6. 把檔案推上去 `git push -u origin master`

這樣基本動作就完成了。

## 方法：

1. 修改 `package.json`

```
{
  // ...
  "homepage": "./", // 新增，用來指定 homepage 的位置，方可抓到對應路徑檔案
  "dependencies": {
    // ...
  },
  "scripts": {
    // ...
    "deploy": "gh-pages -d build" // 佈署的指令
  },
}
```

build 指令要跟 deploy 分開寫，沒辦法放一起。

2. 安裝 `gh-pages`

```
yarn add gh-pages --save-dev
```

上述兩個調換順序，會比較好做，因為一次要部屬三個，覺得這樣比較方便

3. 開始部屬

先打包 `yarn build` ，然後部屬上去，就會多了一個 build 的資料夾。

然後是佈署上去 `yarn deploy`

這樣就完成佈署了，會在 GitHub 上面看到一個新分支 gh-pages，可以切過去，就會看到 build 的資料都在這裡。

然後就可以利用

[你的帳號].github.io/[repository 名稱] 去連進佈署好的靜態網站。
