## Generics

是一種特別的型別，是只在定義宣告時，先不指定具體的型別，而是可以執行的時候才確認型別的特殊方式。

在 array of number 中可以使用：

```
let array1: number[] = [1, 2, 3];
```

來指定型別，其實也可以使用

```
let array2: Array<number> = [1, 2, 3];
```

來做同樣的處理，在 IDE 中，把滑鼠指向 `array2` 會發現他顯示的跟第一個是一樣的：

![](https://cdn-images-1.medium.com/max/800/1*yYsO2_biIVlxaK89qFaQlA.png)

今天假設有一個函式可以回傳最後一個值：

![](https://cdn-images-1.medium.com/max/800/1*G1o3x1n7IXB5z_R00E774A.png)

就可以發現最終結果會得到數字型別，而如果想要處理字串，則會報錯。

![](https://cdn-images-1.medium.com/max/800/1*hlX3rd2xXhWlSM_XLPdJlw.png)

但我們又希望去可以處理的話，要怎麼辦呢？

第一個想到的作法是可以使用聯合型別

![](https://cdn-images-1.medium.com/max/800/1*3cGP9uAi_Ts3Q6Ntnp2r2g.png)

但這都是訂死的，並不能完全解決問題，所以就輪到 Generics type 登場了，我們可以在函數前面加上 `<>` 來指定這是一個 Generics 並且直接使用。

![](https://cdn-images-1.medium.com/max/800/1*epNLMHtMURlBwMfy4mqrVQ.png)

![](https://cdn-images-1.medium.com/max/800/1*21kZcO5zj6rTGvwwwy_pOg.png)

這樣就發現 l1 跟 l2 分別是不同型別了。而 `T` 是一個約定俗成的寫法。
