**crash course computer science** 我從禮拜五晚上就一直抽空看，邊看邊把不懂的內容給搜尋並理解，所以到了今天下午才把整個課程給看完，把整個歷史還有電腦的由來甚至未來講得非常的清楚，我也更加了解到整個電腦科技的發展。禮拜天晚上有先跑進度看了一些課程內容，看了三期，看到要先看 GIT101 於是我就稍微看了一下 GIT101。

## 今天(4/15)

**crash course computer science** 看到下午才看完，後有事情就出門了 **GIT101** 晚上回來繼續看 GIT101。 因為對 GIT 不了解，所以先查詢了一下 GIT 的相關資料，我了解更多GIT：

- GIT 是從 Linus 社群的人自己用 C 語言開發了免費的分布式版本管理系統。
- 了解到什麼是分散式的結構
- 學到 Git init 指令由於我喜歡邊學邊練習 所以我就去找了建立資料庫的方式 mkdir learngit cd learngit pwd D:\\Software\\cmder\\learngit 成功建立資料夾 於是我把之前是先練習的 HTML 檔案直接拿來做使用，結果發現 git 指令無法辨識空白，於是我就去搜尋解決方案，發現只要把檔名加””即可或是在空白的地方添加””也行。 突然對於減號有了疑問 於是查詢之後：
- [特殊符號大全](https://www.cnblogs.com/balaamwe/archive/2012/03/15/2397998.html) “-” 減號 (dash) 此外也是系統指令的選項符號。 ls -expr 10–2

接著看到**想回到過去：git checkout** 。然後決定先寫報告。 看了一下同學的進度報告才發現，原來我要先看 CMD101 才對啊!

## 收穫

- 今日收穫良多，**對於 CLI 有更多的了解**，也是 crash course computer science 的關係吧！我可以理解到為什麼要從 CLI 學起，即便他的指令都是些比較難以記憶的。
- **對於版本控制有更明白清晰的了解了**，我想明天先把 CMD101 補完之後可以有更深刻的了解。
- **英文單字多學了好幾個**，因為 CMD 練習使用的關係，我多學了好幾個英文單字，真是可喜可賀的一件事情。
- 學了一下 **Markdown 語法**，有種似曾相似的感覺，原來我之前用的 Coggle 也是支援同個語法。順便重新學習Markdown 語法的用法。
- **英打的能力增強(或許)**然後再這幾天一直打英文的薰陶之下，我好似英打有變好一些了，可以比較不用看鍵盤打字的感覺又回來了，也許明天測個英打看看。
