## 大綱：

先寫 HTML，然後再把資料抓進去，再做一些功能。

[HTML boilerplate](http://htmlshell.com/)：幫助可以更快開始的模板，通過勾選之後自動生成一個基本的 HTML 架構。

在實作HTML 之後，因為想把時間跟暱稱放在同一排，但是一個在前面一個在後面。這邊有很多種作法可行，用比較簡單的方法就是先在上層設置

```
display:flex;
```

這樣下面的暱稱跟時間就會並排，然後在設置

```
 justify-content: space-between;
```

這樣就可以分開

## 子留言

子留言的部份，就可以利用另外一個 div 包起來，然後共用父留言的結構。但如果子留言要細部修改，就可以利用選擇器去選兩次 class 來些微改變不一樣的地方。因為這樣權重就較重，就可以很方便的修改細節。

## PHP 小技巧

可以另外開一個 php 的檔案之後在引入，可以讓整體看起來比較好看一點。

```
include('template_subcomment.php')
```

template_subcomment.php 裡面放入要 echo 的資料。

也可以使用 require

利用這種方式可以讓整個主網頁看起來比較易讀，在修改的時候也比較方便。

## 註冊

在 register.php 寫入註冊表單之後。因為要上傳伺服器，所以就必須要有上傳的功能。單純表單是不能把資料傳遞給伺服器。

在這裡有兩種方式可以上傳資料，一個是另外引導到 handle_register.php。在這個頁面設置上傳功能。

另一種方式是直接寫在原本的 register.php 上方寫入上傳功能。所以當送出的時候會導入本來的頁面，並且執行上傳的功能。

```
<form action="./register.php" method="post">
```

## 登入錯誤訊息

錯誤訊息可以在 php 的部份設置空字串，然後當帳號密碼錯誤的時候，就在html 裡面判斷該字串是否為空，不為空則印出錯誤訊息。

```
<?php
```

```
$error_message = '';
```

```
if(..登入成功判斷..) {
  登入成功執行
} else {
  $error_message = '請確認帳號或密碼';
}
```

```
?>
```

```
<!doctype html>
...
...
...
```

```
<body>
<?php
if ($error_message !== '') {
  echo $error_message;
}
?>
```

```
...
//　原本的 HTML 部份
```

```
<form>
...
...
```

```
</body>
```

這段就是在最上面的登入成功判斷，失敗之後，就把變數的值改成請確認帳號或密碼。

接著在網頁的部份判斷該字串，如果不是空的，就印出來。

這也是放在同一頁的好處

### SQL 小細節

如果該筆資料是 int 數字格式，就不需要用單引號選起來，因為單引號是給字串使用的。

使用 SQL 指令的時候，JOIN 指令的後面加 WHERE（條件），否則會報錯。

使用 JOIN 指令時，如果抓取下來的資料跟 PHP 數的變數不一樣，那就很簡單的直接使用 as 把該欄位的名稱改成跟 PHP 變數一樣即可。

## 資料庫的設定小細節

設置的資料庫，要一開始就設計好，中間如果變動設定，像是編碼，那麼可能中途就會資料錯亂。

## 註冊後直接登入狀態

通過

```
$last_id = $conn->insert_id; // 這行直接取得執行完的送上資料庫的 id
setcookie("user_id", $last_id, time()+3600*24);
```

這樣就可以直接抓取上傳成功的 id 然後把這個 id 埋進瀏覽器，這樣就可以達到註冊完成之後直接處於登入狀態。

[參考資料](https://www.w3schools.com/php/php_mysql_insert_lastid.asp)

## cookie 的小細節

從 devtool 的 application 裡面可以看到 cookie 的 path

這個 path 就是 cookie 的路徑，預設值就是在取得的那個路徑之下，但可以透過 setcookie 的第三個參數來改變路徑。
