### 基本語法

\# 標題

\## 副標題

\### & ####

```
 **粗體**
```

```
 *斜體*
```

```
 ~~刪除線~~
```

### 進階語法

`程式碼` 把標示內的程式碼變成小區塊

大區塊語法(前面四個空白) ex: 空白空白空白空白程式碼

`語法代號+高亮程式碼` 高亮顯示程式碼

水平線

```
***
---
___
```

表格

```
| 标题|内容|备注|
| ------ | :------:|------:|
|标题1 |内容1|备注1|
| 标题2 | 内容2|备注2|
```

\\ 反斜線：使語法失效
