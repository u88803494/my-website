打開設定之後，在輸入區輸入 emmet 就會顯示如下方頁面：

![點開紅色處。](https://cdn-images-1.medium.com/max/800/1*gkuCxOM_R7m20wKcU3BMcA.png)

_點開紅色處。_

直接在這個 `.json` 檔案裡面新增設定

```
"emmet.includeLanguages": {
  "javascript": "javascriptreact"
},
"files.associations": {
  "*.js": "javascriptreact"
}
```

![](https://cdn-images-1.medium.com/max/800/1*UJyEHCQ1rRlV3WC63V4syA.png)

大功告成。不過 CSS 的部份就還是沒辦法啟用，這要另外在找過了。
