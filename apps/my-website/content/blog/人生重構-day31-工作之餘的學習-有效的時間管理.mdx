## 有效時間管理

在這課程中學習到時間會被浪費的原因以及要怎麼樣有效率的規劃事情並且完成。

### 時間為什麼會被浪費

**心不在焉：**  
一個人的心思應該要處在當前工作，如果沒有處在當前，那他就會很容易因為分心而沒有把工作做好，甚至出意外造成更多的時間浪費。

例如說小明是一個搬貨的員工，但是他總是一邊搬貨一邊想著手遊的事情，這時候他麻煩就來了。他會很容易因為分心而導致他搬貨慢吞吞，進而影響他的工作效率。更糟糕一點的話，他很可能因為分心，不小心就把貨物給砸壞，又或是因為分心而導致自己受傷無法工作，然後他就需要額外的時間來處理這些狀況。

反過來說，假設今天小明每天上班都很用心，他相當的處在工作狀態中，那們他就會不會有什麼意外，或是效率降低的事情發生。

所以這告訴了我們，每一次的工作都應該要用全力的去做，這樣才可以順利的完成。

**沒有計畫：**  
當一件事情沒有任何的計畫或是計畫很模糊，又或是沒有規劃，那將會一片混亂，更糟糕的是可能會出現兩個互相衝突的行動。

例如說，有一家 A 化妝品公司，他們想要推出新化妝品來搶佔市場，但是公司只提出這個想法就交給了業務部門跟 RD 部門而沒有詳細的規劃。那麼接下來就有可能發生一些問題，像是業務部門就會認為公司應該是要走平價路線，於是就開始找宣傳，然後弄海報等等，都是針對會採買平價化妝品的女性，甚至預告也直接寫了公司即將推出平價商品來吸引可能的潛在顧客。而研發部門，則是很可能認為公司需要的是高價路線，可能就會把資源投資在研發更優質高貴的化妝，最終做出要價高昂的化妝品。最後產品要上市了，結果兩邊的部門互相了解後才發現，兩邊的人想得完全不同，但資源已經投入了，除了資源的浪費外，也是浪費了相當多的時間。

當然一般來說公司不太可能因為這麼瞎的理由而浪費時間，但從這個例子中可以看得出來，在工作上經常會因為溝通有落差，而導致的時間浪費，所以假設公司一開始就詳細的規劃好，目標客戶以及更多的細節，甚至也規劃好兩邊的部門應該要給予什麼樣的幫助，那麼這樣子公司就不會浪費太多時間，而且他們溝通可以是很良好的。

接下來就會講講如何規劃這件事情。

## 如何規劃

### 目的與戰略計畫

「戰略」這個字，原來也意味著一個計畫或方法，以引導任何活動，才能達成某個特定的目標或結果。

首先需要設立一個或是多個的明確目的，像是這次我要參加鐵人賽 30 天，我就有運用這樣的概念。

在基於一個目的之下，我們需要訂定一些戰略計畫，戰略計畫是屬於較大範圍的大方向計畫，至於為什麼要從大方向開始呢？因為一般人在訂定計畫時，最長的習慣就是直接訂一些非常細節的計畫。像是想要維持身體健康，就發現自己可能體重有點重，所以大部分人會直接想，那我就來每天跑三十分鐘吧，接著最後就可能失敗。

所以訂定大方向的計畫可能會如下：  
**情況：** 在工程師群組的朋友的建議之下，我參加了鐵人賽，這個鐵人賽需要連續寫文章三十天  
**目的：** 建立一個鐵人賽挑戰的大綱跟詳細內容大致的方向，使自己可以有順序的順暢完成鐵人賽  
**計畫：**

- 研究官方規定：實際去研究就會發現規定的細節，不過這邊只舉幾個簡單的：
- 發文內容應以繁體中文為主（專有名詞不在此限）。
- 每篇發文需多於 300 字（以中文計算，包含標點符號）；且引用部分不得逾全文 1/3。
- 主題選擇：選出一個合適的主題使自己可以順暢完賽，目前主要想法是打算寫關於自己這三年來的經歷以及各種心得，而我也想要先從自己轉職之前的經歷用一兩篇的篇幅寫一寫。
- 文章格式：預期是前面要放引言，用來表達一下這篇文章的重點，然後中間開始撰寫整個故事。最後結尾的時候，要放上一些分享，分享自己當時學習到什麼。對於這件事情有什麼看法、心得、收穫等。
- 文章結構：
- 導讀：撰寫大致上這系列文章會寫到什麼樣的內容，使讀者可以期待我之後會寫出來的內容。
- 自我介紹：目前是希望可以先用一篇的篇幅自我介紹，然後再介紹我在轉職前是什麼樣的人，當做自我介紹。
- 做出改變：然後才是撰寫我接觸到一些演講改變了我的信念，然後讓自己思考到底什麼是我真正想要的，最後做出轉職決策的原因。  
  …等

就這樣就可以大致確認自己整體這次的挑戰要寫些什麼，有了這大致上的戰略計畫，也可以知道自己的內容有沒有辦法寫滿三十天。當然可以看到其中有很多細節沒決定，所以接下來就是在往下延伸做出更細節的規劃

## 戰術計畫

戰術相較於戰略計畫，是指偏向細節的部分，打贏一場戰爭的方向是戰略計畫，而戰術計畫則是小到機槍怎麼擺，要如何攻破一個小陣地，皆屬於戰術計畫的部分。

所以緊接著我們就可以針對計畫的細節訂定計畫，這邊只簡單的舉出簡單的。

**主題選擇戰術計畫**

```bash
# Description:
選出一個合適的主題使自己可以順暢完賽，目前主要想法是打算寫關於自己這三年來的經歷以及
各種心得，而我也想要先從自己轉職之前的經歷用一兩篇的篇幅寫一寫。

# 戰術計畫：
## 預選主題名稱：
1. “轉職三年 web 仔：不僅是代碼，更是人生的重構”

    這個標題強調了我的人生的轉變的重要性，就如同整個程式碼被重構一樣，所以我很喜歡這個標題。

2. "轉職三年，從實驗室白袍到前端黑框眼鏡"

    這個標題感覺很有畫面有趣

3. "三年轉職，一生不同：從化學元素到HTML元素"

    用元素押韻，感覺有趣

## 確定主題：
用一號，因為最貼切又正式，而二三可以作為子標題的參考，但是因為感覺還差一點，
最後定案為「轉職三年 web 仔：不僅是代碼，更是人生的重構」
```

所以一個計畫整體就是這樣，只要按照這樣的步驟一步一步的去完善整體計畫，我就可以知道整場的鐵人賽我應該要做些什麼，每天的文章要如何寫。甚至我把這個計畫弄到夠完整，對我來說寫鐵人賽文章就變成只是一個填空題，因為我連文章格式都決定好了。這也是為什麼我即使每天當天才寫文章，我卻可以每天都寫出三千到五千字的秘密之一。

## 結語

學到這套方法後，我慢慢地開始把我人生目前很多想做的事情都給它規劃下去了，然後規劃完成後，我意識到自己的人生似乎沒有太多時間可以浪費，因為實際要執行的事項非常多。

工作之外，我還喜歡學習，平日也會去健身和進行投資，這些都需要投入時間去學習、規劃和實施。因此，我不僅規劃了職涯發展的方向，也對學習、健身和投資各自的路徑做了全面的規劃。未來若有更多人生需求，我也會適時地新增或更新這些規劃。

除了本篇文章的主題之外，我還進行了許多其他方面的學習。這些不同領域的知識、技能和生活哲學對我的人生都有相當大的助益，我也會持續應用這些學到的東西，讓自己不斷進步。
