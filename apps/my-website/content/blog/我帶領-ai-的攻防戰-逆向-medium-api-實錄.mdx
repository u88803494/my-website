### 前言：擱置數年的心願，短短數天的衝刺

大家好，我是 Henry，一位前端工程師。

翻新個人作品集這個念頭，其實已經在我心中盤旋了好幾年，卻始終停在「想」的階段，一直沒有動工。

阻礙我的並不是技術有多困難，恰恰相反，是我想做的太多、想法太發散。這種「想一次到位」的完美主義，反而讓我陷入了不知該從何下手的困境。

這次，我決定掙脫這個迴圈。我的策略很簡單：徹底遵循 MVP (最小可行性產品) 原則，並將 AI (Cursor + Gemini) 作為我的核心開發夥伴。目標只有一個 — — 先在一個週末內，打造出一個專業、可用、我自己會滿意的 Landing Page V1 版本。

在完成了 Hero、工作經歷等核心區塊後，整體很滿意，但總覺得缺了什麼？所以我花了兩個小時，請 Cursor 為我弄了一個簡易爬蟲，即我提供我想放上的網站文章網址列表，再請他用爬蟲解析。成果如下：

然後我迎來了下一個挑戰：如何將我在 Medium 上累積的上百篇文章，整合到這個新家中？

## 挑戰開始：與 AI 的激烈攻防

我的初步想法很單純：我希望在網站上顯示一個部落格區塊，預先載入 20 篇文章，並且可以無限滾動。最重要的是，我希望這個過程是自動化的，在我部署網站時，它能自動抓取最新的文章。

我將這個需求拋給了我的 AI 顧問 (Gemini)，我們的「偵探遊戲」就此展開。

### 第一回合：RSS Feed 的美好幻想

AI 的第一個建議，是前端開發者的直覺反應：使用 Medium 官方提供的 RSS Feed，並透過一個免費的第三方服務 rss2json.com 來繞過 CORS 問題。這方案聽起來極其簡單，完全不需後端。

我立刻滿懷期待地打開了我的 Medium RSS 連結…

`https://medium.com/feed/@hugh-program-learning-diary-js`

然後，現實給了我第一拳重擊：Medium 的 RSS Feed 只會顯示最新的 10 篇文章！ 這意味著我上百篇的歷史文章完全無法被讀取。這個「最簡單」的方案，在第一步就宣告失敗。

### 第二回合：HTML 爬蟲的複雜提案

既然 RSS 的路走不通，AI 提出了更專業、但也更複雜的方案：建立一個 Next.js 的 API Route，在後端用伺服器去抓取我 Medium 個人主頁的完整 HTML，然後用 cheerio 函式庫像 jQuery 一樣去解析 DOM，從中提取出文章標題和連結。

這個方案雖然可行，但總讓我覺得不夠「優雅」。解析隨時可能改版的 HTML 結構，感覺既脆弱又不穩定。

### 第三回合：身為偵探的「我」，發現了突破口

就在我準備接受爬蟲方案時，一個念頭閃過腦海：「Medium 自己的個人主頁，不也是無限滾動嗎？它背後肯定有自己的 API 吧？」

我立刻打開瀏覽器的開發者工具，切換到「Network」分頁，開始向下滾動我的 Medium 頁面。果不其然！當新文章載入的瞬間，一個特別大的 graphql 請求出現在列表中。

我立刻將這份情報回報給 AI，我們都意識到，這才是真正的「寶藏圖」。

### 第四回合：聯手破譯 GraphQL

我們發現，這支 API 不僅回傳了乾淨的文章 JSON 資料，它的請求 Payload 中，更包含了實現無限滾動的關鍵鑰匙：一個名為 `homepagePostsFrom` 的「書籤」變數。

有了這個發現，我們的最終作戰計畫變得無比清晰：

1. 建立一支後端 API Route。
2. 在這支 API 中，完整模擬我們用開發者工具找到的這份 GraphQL `POST` 請求。
3. 前端頁面則向我們自己的 API 發送請求，並在滾動到底部時，將上一次 API 回傳的「書籤」值帶上，請求下一頁的資料。

我將這個最終的、極其詳盡的計畫，寫成一份完整的指令，交付給我的「施工隊」Cursor。幾分鐘後，一個功能完整、邏輯清晰、且 100% 可靠的後端 API 就誕生了。

> 當然，這裡必須強調，我們所做的只是觀察並複製一個公開可見的 API 請求，目的是在自己的個人網站上，以更有效的方式展示自己在 Medium 上發表的公開內容。整個過程不涉及任何非公開資料，也應在尊重平台服務條款的前提下進行。

## 結語：AI 時代，經驗與好奇心是你的超能力

這次的開發經驗，讓我對 AI 協作有了全新的體悟。AI 確實能為我們省下大量時間，但它並非萬能。它有時會選擇「最直接」的路，卻未必是「最好」的路。

這次，如果我沒有基於開發經驗去質疑「爬蟲是不是不夠穩健？」，如果我沒有那份好奇心去打開開發者工具、親手找出真正的 API，我們可能就會卡在一個不夠理想的解決方案上。

AI 能幫我們快速蓋牆、砌磚，但身為人類的「經驗直覺」與「好奇心」，才是我們手中那份最關鍵的「藏寶圖」，它能指引 AI 走向真正優雅、穩健的康莊大道。
