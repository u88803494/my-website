## 該如何執行 JavaScript？

Node.js 一個可以使我們在電腦上面執行 JavaScript 的執行環境。

可以從官網安裝 Node.js [Node.js 官方網站(中文)](https://nodejs.org/zh-tw/download/)

在資料夾裡面建立一個檔案 index.html

然後就可以在裡面寫

```
<script>
    console.log(123)
</script>
```

案 F12 使用 devTool 開發者工具 就可以在 console 介面看到輸出 123，其實也可以直接在這個頁面輸入程式碼或要執行的內容，就可以看到結果。通常 debug 就會在瀏覽器上面。

## hello world

```
<script>
    console.log(“hello world”)
</script>
```

就可以看到 hello world

如何使用 node.js

在終端建立檔案，index.js 裡面寫

```
console.log(“hello world”)
```

就可以在終端輸入

```
node index.js
```

它就會顯示 hello world

## 基本運算

在終端內，也可以直接輸入 node ，就會可以直接執行 node 指令。如果要離開這個介面就使用 ctrl +c ，然後按照畫面寫的輸入指令。

在這邊就可以使用一般的四則運算 + - \* / () 來計算數值，有個知名問題是10/3 結果輸出 3.3333333333333335 之後詳解

取餘數就是 %，ex: 10%3 就會輸出 1

## 邏輯預算

and &&：ex: true && fales 回傳 fales

or ||：ex: true || true 回傳 true

not !：ex: !true 回傳 false

### 小撇步

|| 與 &&

在 JavaScript 裡面 很多直覺是沒有的東西，就會被當成 false。像是 0、空字串、no、false，都會被當成假的值，所以不是這些就會被當成真的值。

_就可以利用在判斷上面直接判斷，或是回傳結果。2019/05/18 補充_

or ||

```
> 3 || 10 在這裡，因為是 or 所以第一個值為真，就回傳真值 = 3
3
> false || 10
10
> 0 || 10 會等於 false || 10
10
```

and &&

```
> 3 && 10
10 //3 為真，10也為真，第一個為真，第二個為真，結果為真，值回傳為第二個真值
> true && false
false
> true && true
true
>10 && 3
3
>false && 3 → 所以它只看前段的句子(斜體)就可以決定值多少，這就是 &&的短路性
              質，因為它不用判斷第二個值了
false
> 0 && 12357496 // 0 為 false 所以這段也只判斷斜體部分
0
```

因為程式是一行行往下的，所以判斷的時候，例如：

or 它會先第一個判斷的真假，如果為真，回傳的真值，則是第一個真的值。如果第一個判斷為假，再判斷第二個，第二個為真，就回傳真，真值為第二個的值。

and 則是要判斷第一個，之後在判斷第二個，如果第一個為真，第二個也會真，那就會判斷為真，且回傳第二個真值。

### 短路性質：

or 第一個為真時，就直接回傳值，後段就不執行了。and 第一個值為 false 時，直接回傳值，後段就不執行了。

## 位元運算

### 位移運算

符號 &lt;&lt; , >>

針對位元(bit)操作

二進位

0100 = 2^2 = 4

1000 = 2^3 = 8

位移運算就是如上方所示，1 往左移，每移動一格代表的是數字\*2，代號 &lt;&lt;

```
> 10 << 1 // = 10 *(2^1)
20
> 10 <<2 // = 10 * (2^2)
40
> 10 << 3 // = 10 * (2^3)
80
> 1 << 3 // = 1 *(2^3)
8
> 1 << 10 // = 1 *(2^10)
1024
> 1 << 31 // = 1 *(2^31)
-2147483648 //溢位
> 1 << 30 // = 1 *(2^30)
1073741824
> 1024 >> 1  // = 1 *(2^(-1))
512
> 9 >> 1  // = 10 *(2^(-1)) 無條件捨去小數點
4
> 13 >> 1  // = 10 *(2^(-1)) 無條件捨去小數點
6
```

用這種方法算會比較快，因為是調用電腦最原始的形式，所以效能通常比較好。

### 位元運算的 and、or、 not 與 xor

變成二進位之後，對每個位數做運算

and "&"：

10\*1**\*0**

11\*1**\*1**

做 and

會得到 010

方式：同一位相比較，粗體跟粗體的部分比，斜體跟斜體的部分比

所以 只有一個符號 例如：& | 它就會做位元運算

```
> 10 & 15 // = 1010 & 1111 會得到 1010 //這是位元運算
10 // 二進位 = 1010
> 10 && 15 // 邏輯運算
15
```

上列是把 10 跟 15 變成二進位然後對每位數進行運算

Or "|"：

```
> 10 | 15 // = 1010 | 1111 會得到 1111 //位元運算
15 // 二進位 = 1111
> 10 || 15 // 邏輯運算
10
```

xor "^"：

xor兩個都是 1 的話 會傳 0 ，兩個都是 0 還是傳 0 ，其他傳 1，簡單說兩個都一樣就是 0，兩個不一樣則是 1。

```
> 10 ^ 15 //通常我們都用^來做次方運算，但在 JavaScript 裡面，則是代表xor。
5
> 10^15
5
```

not "~"：

not 是把 true 回傳為 false ，false 回傳為 true。

```
> !15 // "!" 是邏輯運算
false
> !0 // "!" 是邏輯運算
true
> ~15 // 位元運算，它會把整個 bits 裡面的值都做位元運算
-16   // 所以 15 = 000....0001111 變成 111...1110000
```

這種情況下連最前面用作判斷數值為正負的值都給做位元運算了，所以得出答案為負值。

1010 & 1 如果後者只有一位數，則它的前面都被視為零 1 = 000...0001

無法理解為什麼值是 "16"，所以拜見估狗大神：

> [參閱](https://developer.mozilla.org/zh-TW/docs/Web/JavaScript/Guide/Expressions_and_Operators)： 注意，**在使用 位元NOT 運算子時， 所有的32個bit都被進行NOT了**，包含最左邊用來描述正負數的位元(two’s-complement representation)。

> [負數如何儲存](https://ithelp.ithome.com.tw/articles/10204950?sc=iThelpR)

> [位元NOT運算 (~)](http://www.86duino.com/?p=1412&lang=TW)

> [參閱補數的運算](http://www.chwa.com.tw/TResource/HS/book1/ch2/ch2-3-1.htm)

**簡單說因為二補數的關係，得到的值必須為原來的值再+1，接著因為最左邊的判斷正負的 bit 從 0 被轉為 1，故得負值。所以 ~15 會得到 -16。**

### 什麼時候用得到位元運算

1010 & 1 = 0000

```
A = 任意數
A & 1 => 0, A 的最後一個位數是 0
A & 1 => 1, A 的最後一個位數是 1
```

1 的位數前面都是 0，所以以 and 來說，可以確定只要有 0 的部分，出來一定是 0，所以就只要看最後一個數字就可以了。

它就有點像遮罩的感覺，就可以東西變零，只要它遮完之後就會變成 0，我們可以選擇要遮哪個位數。

```
A = 任意數 // 8 = 1000
A & 8 => 0, A 的第四個位數是 0
A & 8 => 8, A 的第四個位數是 1
```

從這邊可以判斷第幾個位置的數字是否為 1

在二進位裡面，只要最後一個位數為 1，就一定是奇數。奇數加奇數一定為偶數，奇數加偶數一定為奇數。

使用這個方法，我們就可以判斷該數是不是為奇數，

```
A = 任意數
A & 1 => 0, A 的最後一個位數是 0，A 是一個偶數
A & 1 => 1, A 的最後一個位數是 1，A 是一個奇數
```

之前我們都是用取餘數，餘數為 0 是偶數，餘數為 1 是奇數。現在就可以用位元運算的方法。
