### 新增

然後就是輸入框的部份，在這邊使用 `onChange={this.handleChange}` 來紀錄資料，然後按照原本的方式來用，會發現沒辦法 `onChange` 無法監聽到 enter 的部份。

[Google](https://codeday.me/bug/20180103/114731.html) 之後發現原來要利用另外一種監聽器：  
`onKeyPress={this.handleSubmit}`

```
  handleSubmit = (e) => {
    if(e.key ==='Enter') {
      console.log('yes')
    }
  }
```

```
handleEditingChange = (text) => {
  // 從傳入的改變，id 直接取暫存區的即可。
  const { editingTodo } = this.state
  this.setState({
    editingTodo: {
      ...editingTodo,
      text: text

  })

```

```
handleUpdate = () => {
  const { editingTodo, todos } = this.state
  this.setState({
    todos: todos.map(todo => {
      if (todo.id !== editingTodo.id) return todo
      return {
        ...todo,
        content: editingTodo.text
      }
    }),
    isEditing: false,
    isProcessing: false,
    editingTodo: {},
  })
}
```

handleEditingChange 最簡單，就跟新增的輸入框差不多的內容。

handleUpdate 則就比較多事情一點，這邊就是要把原來的值蓋掉，就要透過 `.map()` 去篩選需要更改的部份在改就好。然後改完之後記得還原原來的部份，把編輯跟背景都關了，然後編輯的暫存區清空。

另外一點這樣寫的好處是可以保存狀態，像是假設我在編輯中關閉視窗，這樣之後要重新整理或是關閉頁面回來的還原應該也是滿容易的。

## 加上 localStorge

要先實作儲存才可以實作取出，所以就先從儲存實作吧

```
componentDidUpdate(prevProps, prevState) {
  // 試著寫會還原狀態的 app
  window.localStorage.setItem('todoapp',
    JSON.stringify(this.state));
}
```

也不難就是把所有狀態儲存而已XD

然後是取出，這部份幾乎都差不多…

```
componentDidMount() {
  const todoData = window.localStorage.getItem('todoapp');
  if (todoData) {
    const oldData = JSON.parse(todoData);
    console.log(oldData)
    this.setState({
      ...oldData
    })
    this.id = oldData.todos[oldData.todos.length - 1].id + 1
  }
}
```

很簡單的改造下就成了。
