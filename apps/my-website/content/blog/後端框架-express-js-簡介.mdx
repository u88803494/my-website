## 要了解後端框架，先從不用框架學起

node.js 本身就有內建指定可供使用。

然後就可以寫一些指令

```
const http = require('http');
const server = http.createServer(handler); // 傳入一個函式
```

```
function handler(req, res) { // 命名習慣上用三字元
```

```
}
```

然後完善這個 function

```
function handler(req, res) { // 命名習慣上用三字元
  console.log(req.url); // 印出就可以看到有無人連入
  res.write('hello'); // 回應 hello
  res.end(); // 表示回應結束
}
```

然後因為這是練習，所以可以監聽別的 port。

```
server.listen(5001); // 監聽 5001 port
```

像是測試的時候，就可以利用別的 port 來測試

接著就可以執行

## 初探 Express

官網

要用的時候首先要初始化資料。

1. 創建一個資料夾  
   `mkdir express-demo`
2. 切入資料夾  
   `cd express-demo`
3. 初始化  
   `npm init`
4. 安裝 express  
   `npm install express`

然後就可以按照 getting start 的例子來試試看
