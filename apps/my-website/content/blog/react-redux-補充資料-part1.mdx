## 打包 API

像在這個案例中，在 `componentDidMount` 寫了一個 call API，那假設今天有很多地方都會用到這個 API，那我們不就寫了一堆差不多的內容，所以這部份也可以另外打包出來。

這種情況就可以另外開一個 webAPI.js 來寫，

把呼叫的部份另外打包即可。

```
import axios from 'axios';
```

```
export const getPosts = () =>
  axios.get('https://jsonplaceholder.typicode.com/posts');
```

同理可證，單一文章的部份也可以另外寫過。

```
import axios from 'axios';
```

```
export const getPosts = () =>
  axios.get('https://jsonplaceholder.typicode.com/posts');
```

```
export const getPost = postId =>
  axios.get('https://jsonplaceholder.typicode.com/posts/' + postId);
```

而且這樣的話，就只需要在 WebAPI.js 引入 axios 就好了。

## redux 管理 response

在目前規模中，我們是把 response 的內容直接放在 state 裡面的，但是在規模大了一些之後，這樣做可能就不是很好的方式，因為我們這樣做可能會額外多出很多不必要的請求。

像是如果有很多地方都會用到這樣的 response 的內容，就可以把它放在 global 的 store 裡面。

這樣的話就會需要新的 action

```
actionTypes.js:
```

```
...
```

```
export const GET_POSTS = "GET_POSTS";
export const GET_POSTS_SUCCESS = "GET_POSTS_SUCCESS";
```

然後寫 action

![](https://cdn-images-1.medium.com/max/800/1*5GqhKSlWapa2DWia9a-Q6Q.png)

在這底因為一個一個 import 太麻煩了，所以改成直接 import 全部，這樣的方式就會讓所有的資料變成處於一個 actionType 的 object 裡面，所以就可以利用 object 的方式呼叫。

然後就可以寫 reducer 了

reducer 也要加上一些預設值，才可以開始寫，所以 state 就要加上去。

![](https://cdn-images-1.medium.com/max/800/1*NK6VSScF8lHp6fvvY3_3UA.png)

![](https://cdn-images-1.medium.com/max/800/1*k5AN-WXXyt86IanPvxxvoA.png)

就可以根據對應的值變更內容，而 data 則是從 actions.js 發送過來的資料。

接著需要開一個 container

把 Posts 傳過來，然後加上資料並且把 Router 給改成這邊，才可以正常運作。

![](https://cdn-images-1.medium.com/max/800/1*LtLKcCLZxALFhv1Z4ENhVA.png)

所以 Post_List 的 API 就可以拿掉了，也不需要 state 了，posts 就可以直接跟 props 拿了，而 Router 就要改給 container 用了。

然後就可以回來寫 `mapDispatchToProps` 了。

![](https://cdn-images-1.medium.com/max/800/1*mpVwPKBN8k_hZYKWGas1Ww.png)

在 `mapDispatchToProps` 中，主要是返回一個叫 getPostList 的物件。這個執行的時候，呼叫 `dispatch` ，並傳入 action 的 `getPosts` 。

然後繼續執行下一行的 webAPI，取得 `getPosts()` 內部的呼叫 API，當得到回應之後，呼叫 `dispatch` ，並傳入 action 的 `getPostsSuccess()` ，然後夾帶著 res.data。這樣就可以把資料寫入 store 裡面。

最後只要在 Post List 的 `componentDidMount` 呼叫這個傳下去的 function，就可以得到全部的資料了。

```
componentDidMount() {
  this.props.getPostList();
}
```
