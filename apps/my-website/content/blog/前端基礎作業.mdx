justify-content 就是一個為內容合理安排的意思。定義了如何分配內容的位置的屬性。參考資料：[詳細版的 MDN](https://developer.mozilla.org/zh-CN/docs/Web/CSS/justify-content) [介紹性的 runoob](http://www.runoob.com/cssref/css3-pr-justify-content.html)

> justify-content 決定了內容元素與整個 Flexbox 的「**水平對齊**」位置，回想一下最上面講的 Flexbox 盒子模型，具有 main start 與 main end 左右兩個端點，justify-content 就是按照這個方式做設定，而其中的設定值總共有下列五個。( 範例：[css-flexbox-demo3.html](https://www.oxxostudio.tw/demo/201501/css-flexbox-demo3.html)、[W3C 說明](http://www.w3.org/TR/css3-flexbox/#justify-content-property) )

align-items

> align-items 剛好和 justify-content 相反，align-items 決定了內容元素與整個 Flexbox 的「**垂直對齊**」位置，再回想一下最上面講的 Flexbox 盒子模型，具有 cross start 與 cross end 左右兩個端點，align-items 與 align-self 就是按照這個方式做設定，設定值總共有下列五個。( 範例：[css-flexbox-demo4.html](https://www.oxxostudio.tw/demo/201501/css-flexbox-demo4.html)、[W3C 說明](http://www.w3.org/TR/css3-flexbox/#align-items-property) )

flex-direction：指定內部元素在主軸的方向。 [MDN](https://developer.mozilla.org/zh-CN/docs/Web/CSS/flex-direction)

-

組合技

```
flex-direction:row-reverse;
justify-content:flex-end;
```

一旦把方向反轉之後，就會變成 start 跟 end 點的交換。所以轉換之後必須要讓他返回原點必須要用 end 來標明

-

```
flex-direction:column;
justify-content:flex-end;
```

這邊在轉換方向之後，方向也跟著改變，所以必須要使用 justify-content:flex-end 來呈現，而不是使用 align-items。

-

order: 可以調整區塊優先度的屬性。

[CSS3教學－透過display:flex的order屬性，就可改成DOM元素的順序](https://www.minwt.com/webdesign-dev/css/18320.html)

根據這邊的測試，是可以讓**區塊根據數字的大小決定先後順序**的方法。

-

接下來碰到 align-self 不太懂與 align-items 的差異，於是找了資料

[align-self vs align-items](https://blog.csdn.net/iefreer/article/details/50776127)

> 其中align-items属性用于弹性容器，而align-self用于弹性项目。

- **flex-wrap** 超出範圍時是否換行的屬性，分為換行、不換行、換行時反轉。參考資料： [MDN](https://developer.mozilla.org/zh-CN/docs/Web/CSS/flex-wrap)

組合技

```
flex-direction:column;
flex-wrap:wrap;
```

先讓橫列變直列，然後在設定換行，這樣的話換行也變成直行了，不在是原本的橫列換行。

-

flex-flow: 因為 flex-direction 跟 flex-wrap 時常一起使用，所以這個是把這兩個屬性合併使用，第一位為 flex-direction 的值，第二位為 flex-wrap 的值。

```
flex-flow: column wrap;
```

所以這樣一行是等同於

```
flex-direction:column;
flex-wrap:wrap;
```

-

接下來是介紹 align-content 跟 align-items 的差異。差在 align-content 可以針對多行，而 align-items 只能針對單行。align-content 確定了行之間的間距，而align-items 確定了整個項目在容器中的對齊方式。

-

最後一題沒提示，自行發揮題。

觀察到紅色位置最下面，按照順序來看必須要反轉。於是就先輸入 flex-direction:column 來反轉並解直行排，後面觀察到青蛙是擠在一坨必須要換行，換了之後因為反轉的關係，所以排版不是人們所想像的，只能在反轉換行，於是青蛙就符合了順序。所以就使用 flex-flow 來把兩者合併。接下來就簡單了，只要把青蛙給置中之後在分開放就好了。

```
flex-flow:column-reverse wrap-reverse;
justify-content:center;
align-content:space-between;
```

## 請問什麼是盒模型（box model）

box model 就是一個把區塊的概念更加進化的工具。讓我們可以把元素看成一個盒子，去控制一些設定，讓版面變成我們想要的樣子。

可以從 chrome dev tools 可以看到一個盒子。

![](https://cdn-images-1.medium.com/max/800/0*5J0oM1mU1OEbECvw.png)

這就是用來乘載元素所使用的盒模型，利用這個盒模型可以定義 margin border padding。分別是外距、邊框、內距。利用這幾個屬性可以讓我們很輕易的排版出我們要的樣子。

## 請問 display: inline, block 跟 inline-block 的差別是什麼？

inline：在排版的時候，會按照順序排列在同一行上面，也因為如此，也有一些設定值不能更動，所以靈活性會少一些。

block：排版的時候，如果 display 設置的屬性是 block，他會每個 block 都會換行。幾乎所有的設定都可以設置。

inlin-block：這個屬性就是 inline + block 的屬性，既有 inline 的特性，又有 block 的特性。inline-block 可以不用換行，而且又可以使用所有的屬性， margin. border. padding 都可以使用，所以是最靈活的 display 屬性。

## 請問 position: static, relative, absolute 跟 fixed 的差別是什麼？

static 是瀏覽器的預設的。不會被特別的定位，就是按照排版出現。

relative 跟 static 類似，relative 是相對定位，意思是可以相對於原始的位置來做移動。

absolute 絕對定位，需要有個參考點，所以 absolute 會參照上一層有無定位，如果有就會按照該層來做絕對定位，如果沒有就往上找，最後如果都沒有就會以 body 來做定位。

fixed 是按照瀏覽器的位置來做相對定位。所以可以設置到任何地方，而且 fixed 不會跟其他的元素干擾。
