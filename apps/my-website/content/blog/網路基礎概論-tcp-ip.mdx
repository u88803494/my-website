## 網路的層級

參考資料：[鳥哥的網站](http://linux.vbird.org/linux_server/0110network_basic.php#whatisnetwork_comps) （較難但完整）

要從最底層的實體的開始，像是海底電纜，中華電信機房到我們社區的線路，甚至是數據機到我們電腦的網路線。後來才是電腦的軟體方面的處理，所以這是有很多層面。

每一層都會有自己的協議，這些協議有個模型叫做 OSI 七層協定可以解釋。但是因為太嚴謹了，所以實際上並不會用這種模型，因為太複雜了，而是使用 TCP/IP 模型。

HTTP 是建立在 TCP 上面的，TCP 又是建立在 IP 上面的，所以是一層層的關係，分層的好處是只要處理該層該處理的事情就好。

## IP 地址

Internet Protocol address

以 IP 地址來說，可以用自己的電腦來查詢內網 IP

IPv4

IPv6 較新版本的 IP ：目的是解決 IP 位置不夠用的問題。

## 虛擬 IP、浮動 IP 與固定 IP

理想狀況是一個電腦就一個 IP，就可以直接互相連線，這就是固定 IP。

浮動 IP 每次連線上網的時候 IP 都不同。專門給一般用戶使用的，好處是被駭客知道 IP 位置，但是下次連線的時候，位置又不同了駭客就找不到你了。

很多時候，我們也不太需要 IP ，因為不需要別人連到我的電腦，所以就會透過數據機，然後數據機在分配虛擬 IP 給我們，這就是內網，內網就是只有在內網的幾個人可以互相連線，外面的網路無法連接到內網裡面的電腦，但當內網的電腦連接到外面的時候，IP 就會顯示數據機的固定或浮動 IP。

所以電腦 A 要連接到網路的時候，像是連線到 Google ，透過數據機連到 google.com，google.com 只能看到我們的對外 IP，google.com 傳 response 的時候，是傳給數據機，只有數據機知道是誰發出的 request，所以數據機會再把收到的 response 交給電腦 A，中間是透過數據機來轉換的，對 Google 而言只看得到數據機，對電腦 A 而言，只看得到數據機。

額外的把鳥哥的網路基礎看了看，讓我更了解以前用電腦的時候會用到的那些東西，像是 MAC MTU 等，一路往下看到子網路遮罩，才知道原來 IP 還可以區分不同的區網，我想我家可能是更動到什麼了，我的區網才會筆電跟桌機彼此看不到吧！

## Port 連接埠（端口）

用來標示服務的端口，一個 port 就是對應到一個程式。如果有程式在監聽那個 Port 的話，就可以與那個程式溝通。如果沒有打冒號的話，就是預設使用 80，HTTP 的服務

```
常用 Port：
HTTP 80
HTTPS 443
FPT 21
```

就是為了讓我們區別同一台電腦的不同服務。

一般來說自己在測試的時候，常用 3000、4000、8080。1000 以下有很多是其他服務在使用的 port，所以不會拿那些來測試。

## TCP 與 UDP

這兩個是傳輸層的應用。確認動作的應用，確保連線是順利的。

TCP 是一個可靠的連接，它會保證送達，大部分的網路的協議都是應用這個。

UDP 需要的是快速的時候，應用在視訊的時候，要求的是快，所以偶爾丟了一兩個封包是沒關係的。

## TCP 三次握手

過三次握手的方式來建立連接，它會傳定一些特定的東西來確保連線建立。實際的運用是比較複雜的。

## 總結：

HTTP、FTP 等：應用層，內容。

TCP/UDP：傳輸層，就是確認封包或是一直傳封包。決定如何傳。

IP：網路層，收發 IP 位置等資訊。

鏈結層：實體層、鏈結層，網路硬體等。
