註解

把程式碼往上提升 `option + 箭頭向上/箭頭向下`

單行註解

```
cmd + /
```

有條件限制需要把輸入法切成 ABC 才可以用

```
cmd + k + c // 註解所選
```

取消註解

```
cmd + k + u
```

多行註解

```
option + shift + a
```
