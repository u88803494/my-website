如何在 GitHub 開啟 BLOG

本次操作取自：https://pages.github.com/

我操作 User or organization

  1. 建立 repository，repository name 輸入 "註冊時 GitHub的帳號.github.io"
  2. 在 Cli 介面輸入
git clone https://github.com/u88803494/u88803494.github.io

3. 在 Cli 輸入

cd JavaScriptLearning.github.io
echo "Hello World" > index.html

4. 把資料 Push 到 GitHub

git add .
git commit -m “Initial commit”
git push -u origin master

就完成了 網址：https://u88803494.github.io/
