2019/04/17 學習進度與心得

今天(4/17)學了什麼？

  • 火球術，在這邊再次的熟悉了一下程式的原理，知道了重點是在於對於問題的解法，所以認為有必要加強自己的邏輯能力。
  • 第三期實驗課程到第一周，其實這邊有再次強調了，交作業的流程，後來寫作業的時候，有試著不參考任何資料，獨立回想如何作業，這使我更清楚，整個作業流程，也更清楚整個 GitHub Flow 是如何運作的。
  • Markdown 因為發覺 Markdown 語法在這門課程有更多更多的應用，於是我又花了更多哦時間去學習如何使用，有找到了更多的語法可以使用，也開了 Medium 來記錄那些語法，想寫一篇清楚的 Markdown 的入門方法來介紹一下，順便加強自己對 Markdown 語法的熟悉度。
  • week 1 hw 1 這個作業試著自己獨立思考，如何實作，比較覺可惜的是我在到 GitHub 那邊就稍微卡住了，然後就觀看一下影片之後，就更清楚如何時做，也已經完成了第一個作業。
  • Medium 也有稍微查詢了一下如何使用，我更明白一些用法，向是如何額外標示 Code，這樣我的文章就不會看起來亂七八糟了。

感受

今天很用心的把剩餘的部分給完成了，當周該看的內容都完成，所以就開始寫作業，要寫作業的時候就有看到一些壓力，會突然覺得，我真的有辦法好好地寫出來嗎？也不小心花了一點時間又把課程大綱稍微看了一下，覺得自己又開始想太多，所以花了一點時加把自己拉回來。而後又開始寫作業，在寫到 hw1 的時候，就有稍微卡了一下。好在是前面有認真上課，所以大致都想得起來，可能就是操作不熟悉而已。

收穫

今日我更加的明白，一些網路最基礎的原理了，課程上也說明得很清楚，所以我更加明白 request 跟 response 的用法了，而且大致上該學到的內容在 [CMD101] 、[GIT101]、[CS101] 都有說到了，所以會覺得在看二期 1–1 的時候覺得重複性滿高的。 也有不重複的內容，向是 JavaScript 這邊有稍微說了一點程式的概念，對於這些先了解之後在上 [JS101] 應該會有不小的幫助，我看 [JS101] 的內容也扎實的。這是個很不錯的挑戰。
